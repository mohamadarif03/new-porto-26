# 🚀 Portfolio Website — Mohamad Arif

Personal portfolio website yang menampilkan perjalanan karier, proyek-proyek, sertifikasi, dan kontak profesional. Dibangun dengan teknologi modern dan desain yang elegan untuk memberikan pengalaman pengguna terbaik.

> _"Passionate web developer currently expanding into data science, driven to create smarter and more impactful digital solutions."_

---

## 📋 Deskripsi

Website portfolio ini dirancang sebagai pusat informasi profesional yang menampilkan pengalaman kerja, keterampilan teknis, dan pencapaian selama berkarier di bidang **Web Development** dan **Data Science**. Website ini dibangun menggunakan pendekatan **Single Page Application (SPA)** dengan React dan dilengkapi berbagai animasi interaktif untuk memberikan pengalaman yang modern dan premium.

Proyek ini di-deploy secara otomatis menggunakan **Vercel** dan dapat diakses secara publik sebagai representasi digital dari portofolio profesional.

---

## ✨ Fitur Website

### 🏠 Homepage
- **Hero Section** — Perkenalan diri dengan foto profil, statistik karier (2+ tahun pengalaman, 15+ proyek, 8+ sertifikat), dan tombol download CV
- **Tech Stack Marquee** — Animasi auto-scrolling yang menampilkan logo teknologi yang dikuasai (PHP, Go, React, Python, Pandas, NumPy, TypeScript, Tailwind CSS)
- **My Journey Section** — Timeline perjalanan karier dari 2023 hingga sekarang dengan detail peran dan perusahaan
- **Projects Showcase** — Horizontal scroll interaktif yang menampilkan proyek-proyek pilihan dengan efek parallax
- **Certifications Preview** — Grid sertifikasi terbaru dengan tombol "View All" untuk melihat selengkapnya
- **Contact Section** — Form kontak dan tautan sosial media (LinkedIn, GitHub, Instagram)

### 👤 About Page
- Profil lengkap dengan bio dan foto
- **Stats Dashboard** — Visualisasi pencapaian dalam angka
- **Experience Timeline** — Tampilan seperti LinkedIn dengan detail setiap posisi:
  - 🔬 **BCC Community** — Data Science Member (2026 – Present)
  - 💼 **Jobnation.id** — Web Developer Freelance (2025 – 2026)
  - 🏢 **PT Humma Teknologi** — Mentor, Web Developer, dan Intern (2023 – 2025)
- Expandable detail per posisi dengan daftar skills dan bullet points

### 💼 Projects Page
- **Filter Kategori** — Filter proyek berdasarkan "All", "Web Development", dan "Data Science"
- **Project Cards** — Kartu proyek dengan gambar, deskripsi, tech stack, role, dan highlights
- **Animasi Transisi** — Efek animasi saat berpindah kategori
- Proyek yang ditampilkan meliputi:
  - 🤖 **CobyLearnAI** — Platform AI untuk merangkum materi pelajaran
  - 🏗️ **SIPJAKI** — Sistem Informasi Pembina Jasa Konstruksi
  - 📱 **Squad Hub** — Aplikasi fintech mobile
  - 📊 **Kejar Taff** — Dashboard analitik real-time
  - 📚 **Get Skill** — Platform e-learning interaktif
  - 🧠 **Dolfin Brain** — Platform NLP bertenaga AI

### 🏆 Certifications Page
- **Overview Stats** — Total credentials, courses completed, achievements won
- **Skills Cloud** — Tag cloud dari semua skills yang tervalidasi
- **Filter System** — Filter berdasarkan "All", "Course", dan "Achievement"
- **Bento-style Grid** — Layout modern untuk menampilkan sertifikat
- **Detail Modal** — Klik sertifikat untuk melihat detail lengkap (issuer, tanggal, credential ID, level, deskripsi)
- Sertifikat dari: **Dicoding**, **IBM**, **Sanbercode**, **T-Arts**, **ITC**, **BCC**, **Hummatech**

### 📬 Contact Page
- Form kontak dengan field Name, Email, dan Message
- Tautan langsung ke email, LinkedIn, GitHub, dan Instagram

### 🎨 Fitur Tambahan
- ✅ Fully Responsive Design
- ✅ Smooth Page Transitions
- ✅ Fixed Navigation Bar dengan efek scroll
- ✅ Client-Side Routing (tanpa reload halaman)
- ✅ Micro-animations & Hover Effects
- ✅ Modern Typography (Outfit & Playfair Display)
- ✅ Dark Aesthetic Theme

## ⚙️ Cara Menjalankan Project

### Prerequisites

Pastikan sudah terinstall di komputer kamu:

- [Node.js](https://nodejs.org/) (versi 18 atau lebih baru)
- [npm](https://www.npmjs.com/) (biasanya sudah terinstall bersama Node.js)
- [Git](https://git-scm.com/)

### Langkah-langkah

**1. Clone Repository**
```bash
git clone https://github.com/mohamadarif03/new-porto-26.git
cd new-porto-26
```

**2. Install Dependencies**
```bash
npm install
```

**3. Jalankan Development Server**
```bash
npm run dev
```

**4. Buka di Browser**
```
http://localhost:5173
```

### Perintah Lainnya

| Perintah | Keterangan |
|----------|------------|
| `npm run dev` | Menjalankan development server |
| `npm run build` | Build untuk production |
| `npm run preview` | Preview hasil build |
| `npm run lint` | Menjalankan linting |

## 🎨 Penjelasan UI/UX

### Design Philosophy

Website ini dibangun dengan prinsip **"Modern Minimalism meets Dark Elegance"**, menggabungkan estetika gelap yang premium dengan elemen interaktif yang halus.

### Konsep Desain

| Aspek | Implementasi |
|-------|-------------|
| **Color Scheme** | Dark theme dominan dengan aksen terang untuk kontras dan readability |
| **Typography** | Kombinasi **Outfit** (modern sans-serif untuk body text) dan **Playfair Display** (elegant serif untuk aksen) |
| **Layout** | Mixture of full-width hero sections dan grid-based content areas |
| **Navigation** | Fixed navbar yang berubah tampilan saat di-scroll (glassmorphism effect) |
| **Animations** | Micro-interactions pada hover, transisi halaman yang smooth, dan parallax horizontal scroll |

### User Experience Highlights

- 🎯 **Intuitive Navigation** — Menu navigasi yang jelas dengan indikator halaman aktif
- 📱 **Responsive Design** — Tampilan optimal di semua ukuran layar (mobile, tablet, desktop)
- ⚡ **Fast Loading** — SPA architecture dengan Vite memastikan loading time yang minimal
- 🖱️ **Interactive Elements** — Hover effects pada kartu proyek, expand/collapse pada experience timeline, dan modal view untuk sertifikat
- 🎬 **Smooth Transitions** — Animasi perpindahan filter dan page routing tanpa jeda
- ♿ **Accessibility** — Semantic HTML, aria-labels pada icon buttons, dan keyboard navigation support (ESC untuk menutup modal)
